# Data licence policy

The catalog is a compilation with source-specific rights; it must not imply one licence for all imported data.

Every released assertion must carry its source release and licence decision. Releases generate machine-readable and human-readable attribution notices.

Original Hortinis-authored assertions are licensed under CC BY 4.0. Imported assertions retain their source-specific rights; neither that original-assertion licence nor a compilation licence overrides them.

Commercial profiles accept CC0, public-domain data, CC BY data, verified CC BY-SA data and licences explicitly approved as compatible with commercial redistribution. A release database containing ShareAlike material must meet the applicable ShareAlike terms. CC BY-NC, unknown, unverified and inseparably mixed-rights content is excluded.

Pipeline code is licensed under AGPL-3.0-only. Pipeline code and catalog data are separate works; the code licence does not change imported-data rights.
