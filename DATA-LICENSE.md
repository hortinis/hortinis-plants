# Data licence policy

The catalog is a compilation with source-specific rights; it must not imply one licence for all imported data.

Every released assertion must carry its source release and licence decision. Releases generate machine-readable and human-readable attribution notices.

The clean commercial profile accepts CC0, public-domain data, CC BY data and licences explicitly approved as compatible with commercial redistribution. CC BY-SA data is quarantined unless the project explicitly accepts the associated ShareAlike obligations. CC BY-NC, unknown and unverified rights are excluded.

Pipeline code and catalog data are separate works. The code licence does not change imported-data rights.
