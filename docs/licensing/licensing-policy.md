# Licensing policy

## Release gates

- CC0 and public domain: allowed.
- CC BY and approved Open Licences: allowed with attribution.
- CC BY-SA: allowed only after record-level verification and acceptance of the ShareAlike obligations for the target artifact.
- CC BY-NC: forbidden in commercial release profiles.
- Unknown or unsupported rights: forbidden.

Metadata rights do not automatically cover an underlying publication, image, quotation or linked page. Images are separate records with separate rights.

Each release must contain an attribution manifest with source, version, URL, licence, required notice and included records. The compiler must fail on forbidden or unknown assertions.

When an adapted release database is subject to ShareAlike, its manifest and human-readable notice must identify the compatible ShareAlike licence, modifications and absence of additional restrictions. Public repository access alone does not satisfy these conditions.

Practical Plants NC blocks must remain distinguishable throughout extraction. ShareAlike blocks become eligible only after that distinction is reliable. CropGraph's declared licence is not sufficient when its source field does not identify the underlying work.
