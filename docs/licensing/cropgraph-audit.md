# CropGraph licence and provenance audit

CropGraph code is MIT-licensed and its data declares CC BY 4.0, but includes source strings for organizations, books and extension material.

The declared file licence does not by itself prove that every upstream source permits redistribution. Before a record enters a commercial profile, the importer must retain an exact source citation and the audit must confirm that the cited work supports the record and permits the intended use.

Until then, CropGraph is candidate evidence and schema input, not authority. Its windows, climate modifiers, relationships, pests and succession structures remain design inputs.
