# Practical Plants licence audit

Practical Plants has mixed rights: archive-level information describes CC BY-SA material, while pages contain `cc-nc`/PFAF Non-Commercial blocks.

The recovered parser retains locations but not reliably the block-level NC marker. It is not commercially cleared until licence-aware extraction is complete.

Required treatment:

- restore the source block's licence class during extraction;
- exclude all NC prose from commercial profiles;
- retain only independently cleared structured facts;
- admit ShareAlike-derived content only after block-level verification and application of the target artifact's ShareAlike policy;
- preserve page, section and field locators;
- generate an audit report showing excluded records and reasons.

Practical Plants remains useful for gap discovery when a block cannot be redistributed.
