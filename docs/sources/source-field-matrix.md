# Source-to-field matrix

| Canonical domain | Primary source | Secondary source | Release policy |
|---|---|---|---|
| Accepted scientific identity | WFO | TAXREF | Core |
| French identity and status | TAXREF | Editorial review | Core |
| Common names | TAXREF, GROW | Editorial review | Core with locale |
| Trait vocabulary | Crop Ontology | Catalog registry | Core schema |
| Sun, soil, drainage and water | GROW; eligible Practical Plants fields | USDA PLANTS | Context-qualified |
| Life cycle and growth habit | Practical Plants structured fields | GROW, USDA | Licence-qualified |
| Germination and planting windows | GROW | Reviewed regional sources | Core where covered |
| Cold sensitivity | GROW and reviewed sources | Practical Plants | Required for MVP coverage |
| Cultivar timing | Reviewed sources and editorial work | Supplier data after rights audit | Limited initially |
| Pest and disease facts | Individually cited authorities | CropGraph candidates | Post-MVP unless required by an accepted rule |
| Companions and rotations | Individually cited evidence | CropGraph | Deferred |
| Field-crop global seasonality | WorldCereal | — | Priors only |
| Images | Individually licensed assets | Wikimedia Commons | Excluded initially |

No source is allowed to supply a value outside its documented geographic, production-system or cultivar scope.
