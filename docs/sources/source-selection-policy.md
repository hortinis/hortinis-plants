# Source selection policy

A source is accepted only when identity, version, publisher, geographic scope, licence and update status are documented.

It must also state which claims it supports. A taxonomic backbone supports identity, not cultivation timing; a global field-crop calendar supports broad seasonality, not household transplant dates.

Crowd-sourced or derived sources may provide candidate assertions, but they require an explicit quality grade and cannot silently become authoritative because they are convenient to parse.
