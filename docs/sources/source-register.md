# Source register

| Source | Intended use | Licence status | Release treatment |
|---|---|---|---|
| World Flora Online Taxonomic Backbone | Global accepted names, synonyms, ranks and families | CC0 for the backbone; page content can have other licences | Core identity source; pin a static release |
| TAXREF | French taxonomic identifiers, names and status | Etalab/Open Licence | Core France bridge; pin a version |
| GROW Edible Plant Database | European germination, growing parameters and planting/harvest calendars | CC BY 4.0; images separately licensed | Core for covered edible plants; exclude uncleared images |
| Crop Ontology | Trait vocabulary and definitions | CC BY 4.0 | Schema vocabulary, not direct cultivation values |
| Practical Plants | Structured environmental and biological facts | Mixed CC BY-SA and CC BY-NC-SA | Per-block licence audit; NC excluded; SA quarantined pending policy |
| CropGraph | Calendar, pest, companion, rotation and succession candidates | Declared CC BY 4.0, but upstream evidence must be verified | Candidate assertions only until exact citations are audited |
| USDA PLANTS | North American distribution and characteristics | Plant information stated as free for any use; images vary | Secondary, geography-qualified data |
| WorldCereal | Coarse global cereal seasonality | Use only after checking the specific artifact rights | Prior for field crops, not garden dates |
| FAO AGRIS | Agricultural publication metadata | CC BY 3.0 IGO for the metadata | Discovery only; referenced publications retain their own rights |
| Growstuff | Community planting observations | CC BY-SA 3.0 | Optional quarantined signal |
| OpenFarm | Gardening guide candidates | Data declared CC0; project archived | Optional candidate data with quality and availability audit |

The source register is not a blanket permission statement. The exact release, record and upstream licence must be recorded before publication.
