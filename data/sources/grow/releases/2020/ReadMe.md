This file describes how to open and examine  the GROW EDP datasets.

**plant1.accdb**
This is an Microsoft Access database file containing information on 146 edible plant species. The file is 5.4Mb big and can be opened by Microsoft Access on a suitable Microsoft Windows machine. 

A Mac machine will need an Access viewer utility to view the file. We used MDB ACCDB Viewer:

https://apps.apple.com/gb/app/mdb-accdb-viewer/id417392270?mt=12

**PlantingCalendar.xlsx**


This is an excel spreadsheet with planting data information for the plants in the access database.  The file is 162Kb. The Spreadsheet contains dates for 12 locations across Europe, each on a separate tab.

To view the file:

On Windows use Microsoft Excel

On MAC use Microsoft Excel or Apple Numbers.
